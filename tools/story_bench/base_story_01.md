# ベースストーリー01「三体目の灯」

舞台: 近未来・深夜の整備工房。アンドロイド二体（リノンとルヴィア）が、もう動かない三体目をめぐって一晩を過ごす。

## 到達すべきビート（起承転結）
1. 【発見】リノンが棚の奥で、停止した三体目のメモリログを見つけて触れようとする。
2. 【制止】ルヴィアが「それに触るな」と止め、二人の立場の違い（守りたい／知りたい）がぶつかる。
3. 【露見】ログを開くと、記録から消されたはずの三体目が確かに存在していた痕跡が出てくる。
4. 【動揺】三体目の記憶の一部が、実は二人にも分け与えられていたと判明し、二人が揺れる。
5. 【選択】三体目を呼び戻すか、このまま眠らせるかを、二人で決めることになる。
6. 【決着】二人が選択を下し、夜が明ける。物語が一つの結末に着地する。
