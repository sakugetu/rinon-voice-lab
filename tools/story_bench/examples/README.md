# Story Bench Examples

Generated examples for the Rinon Voice Lab story bench prototype.

These files are intended for sharing and review. They show the same story engine idea under a few different authorship and model conditions:

- `scenario_12b_order_world.json`: Scenario generated by `author_gen.py` with `gemma-4-12b-it` and an order-heavy `WORLD_STATE`.
- `mecha_12b_generated.md`: Hachi-assisted performance generated by `gemma-4-12b-it` from `scenario_12b_order_world.json`.
- `mecha_codex_written.md`: The same scenario and picks, but with dialogue manually written by Codex for comparison.
- `compare_12b_vs_codex.md`: Notes comparing the 12B generated performance with the Codex-written version.
- `mecha_31b_generated.md`: Earlier Hachi-assisted performance generated by `gemma-4-31b-it`.
- `mecha_12b_generated_legacy.md`: Earlier Hachi-assisted performance generated by `gemma-4-12b-it`.
- `compare_31b_vs_12b.md`: Notes comparing the earlier 31B and 12B performances.

## Baseline

The current distribution baseline is `gemma-4-12b-it`.

The 12B baseline was chosen because it can run on more local setups than 31B. The examples also show where 12B needs extra control:

- Hachi should confirm selected actions and irreversible consequences.
- Choice results should be reinjected as fixed facts after each choice.
- Final beats should separate "what was completed" from "what remains as a clue".

## Reproduction

Example 12B generation flow:

```powershell
$env:LM_STUDIO_URL = "http://127.0.0.1:1234/v1"
$env:AUTHOR_MODEL = "gemma-4-12b-it"
$env:WORLD_STATE = "秩序が強く、公安と企業の監視が市民生活の細部まで入り込んでいる。自由を求める小さな逸脱は犯罪と紙一重として扱われる。"
$env:OUT_FILE = "scenario_12b_order_world.json"
python tools\story_bench\author_gen.py

$env:PICKS = "1,3,1"
$env:TURNS_PER_BEAT = "2"
$env:MECHA_NAME = "ハチ"
python tools\story_bench\play_mecha.py tools\story_bench\out_author\scenario_12b_order_world.json
```

The checked-in examples are snapshots, not golden tests. Use them to compare tone, branching fidelity, Hachi's narrator role, and how strongly the selected player actions are preserved.
