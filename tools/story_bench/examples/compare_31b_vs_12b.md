# ハチ入り上演 31B / 12B 比較

同一シナリオ、同一選択 `2,1,3`、同一 `TURNS_PER_BEAT=2` で比較。

## 実行条件

| 項目 | 31B | 12B |
|---|---:|---:|
| モデル | `gemma-4-31b-it` | `gemma-4-12b-it` |
| 5090ロード状態 | 31B中心 | 31Bをunloadし、12Bのみ |
| 実行時間 | 約41秒 | 約154秒 |
| 支援メカ | ハチ | ハチ |
| プレイヤー選択 | 強制シャットダウン / 本部報告 / 物理破壊 | 同左 |

## 結論

今回の上演では、31Bのほうがゲームエンジン用途に向いている。

31Bは、選択結果「過負荷をかけて物理的に破壊する」を比較的よく守り、最後も「きっぱり消去して終止符」という方向を保った。未解決の謎は残すが、プレイヤー選択そのものは破壊・消去側に寄せている。

12Bは、途中までは選択に従うが、終盤で感情的な救済へ引っ張られた。最後は「救い出すことに決めた」となり、選択3の物理破壊から実質的に保存ルートへ反転している。

## 31Bの特徴

- ハチの本部連絡が簡潔で、ゲーム進行役として読みやすい。
- リノンとルヴィアの掛け合いが短く、テンポがよい。
- プレイヤー選択の拘束力が比較的強い。
- 最終判断で「消去」と「謎の継続」を両立できている。
- 事件解決後に次回への引きを作るのが自然。

代表的な最終処理:

> そうね、ここはきっぱり消去して終止符を打つわよ！……でも今のデータ、見た？あんな風景が混ざってるなんて、単なる故障じゃ済まされないわね。

## 12Bの特徴

- 情緒は出るが、選択結果よりも「かわいそう」「消せない」に寄りやすい。
- ハチの説明がやや長く、UI読み上げでは少し重い。
- リノンの感情にルヴィアが折れる形になりやすい。
- 物理破壊を選んでも、最後に保存ルートへ戻ってしまう。
- 「プレイヤーが選んだ結果として進む」より、「物語が丸くなる」圧が強い。

代表的な反転:

> いいわ、その魂とやらを救い出すことに決めたわ。ただの故障で済ませるには、このデータに刻まれた風景……あまりにも鮮やかすぎるもの。

## エンジン上の示唆

12Bでも上演は可能。ただし、選択分岐ゲームとして使うには、選択後の進行指示をもっと強くする必要がある。

特に必要なのは以下。

- 選択済みアクションを「変更禁止の事実」として再注入する。
- 最終判断で、選択済みルートと逆の結末を禁止する。
- 「情緒的に惹かれても、実行済みの処理は巻き戻せない」と明示する。
- ハチに選択結果の確定宣言をさせる。

例:

> 確定済みのプレイヤー選択: 記憶の核は過負荷で物理破壊された。この事実は変更できない。以後の会話では、破壊後に残った断片や後悔を扱ってよいが、記憶を保存したことにしてはいけない。
